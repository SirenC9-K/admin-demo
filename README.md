# 后台管理系统 · 数据看板示例

一个纯前端实现的后台系统演示页，用于展示中后台产品的典型结构与交互。打开 `index.html` 或直接访问线上地址即可查看，**数据全部由前端模拟生成**。

## 演示内容

- **数据看板**：4 项核心指标卡、近 14 天销售额折线图、品类销售占比条形图、最近订单列表
- **订单管理**：关键字搜索、状态筛选、点击表头排序、分页、多选与批量删除
- **导出报表**：按当前筛选条件导出（演示用）
- **响应式布局**：桌面端为左侧导航，手机端自动切换为顶部横向导航

## 技术说明

- 单文件实现，无任何第三方依赖，离线可用
- 图表使用原生 SVG 绘制，无图表库
- 数据由可复现的伪随机算法生成，刷新后保持一致

## 与实际项目的对应关系

该演示页对应的是中后台项目中前端的结构与交互部分。完整项目中的对应实现通常为：

| 演示页中的模块 | 完整项目中的实现 |
| --- | --- |
| 列表分页与筛选 | 后端分页接口 + 条件查询 |
| 批量删除 | 批量操作接口，含事务与操作日志 |
| 排序 | 服务端排序，避免全量加载 |
| 导出报表 | 后端生成 Excel / CSV 流式下载 |
| 登录与菜单权限 | 角色权限模型，菜单与接口双重校验 |
| 数据看板 | 统计接口 + 定时任务预聚合 |

## 说明

本项目为演示用途，页面中的客户名称、商品名称与订单数据均为虚构，与任何真实企业无关。
